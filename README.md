# Section Hero Project

A responsive website hero section built with HTML and CSS for Web Systems and Technologies Activity 5.

## Overview

This project features a clean, minimalist hero section inspired by modern developer portfolio websites. It introduces an aspiring software developer and provides navigation to different sections of the page.

## Features

- Navigation links for Home, About, Projects, and Contact
- Main headline and supporting description
- Call-to-action button linking to the Projects section
- Decorative visual card with a programming theme
- Responsive layout for desktop and mobile screens
- Hover effects for interactive elements

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS media queries

## Project Structure

```text
section-hero-project/
├── index.html
├── style.css
├── assets/
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Resize the browser or use its device preview to test the responsive layout.
